# E-PİN Dijital Lisans Platformu – WordPress Tema & Eklenti İskele

Bu depo, koyu temalı dijital ürün mağazası için WordPress + WooCommerce tabanlı geliştirme ortamının ilk adımını içerir. Proje; özel tema, WooCommerce şablon override'ları ve kod havuzu yöneten bir yardımcı eklenti iskeleti sunar.

## İçerik

- `theme/` – OH Digital özel teması
  - `assets/` – SCSS, derlenmiş CSS ve JS kaynakları
  - `templates/` – WooCommerce ve sayfa şablonları
  - `inc/` – Tema ayarları, WooCommerce override'ları ve REST uç noktaları
- `plugins/oh-digital-delivery/` – Kod havuzu ve teslimat altyapısı için başlangıç eklentisi

## İlk Özellikler

- Tema aktivasyonunda örnek PUBG UC ürünü oluşturma
- Terra Wallet, PayTR, İyzico vb. için rozet ve entegrasyon kancaları
- WooCommerce `archive-product`, `single-product`, `content-product-card` özel şablonları
- REST API ile cüzdan bakiyesi ve teslimat tetikleyici uç noktalar
- Kod havuzu tabloları ve admin menü iskeleti içeren özel eklenti

Takip eden görevlerde abonelik, lisans teslimatı, yönetim panelleri ve detaylı UI bileşenleri eklenecektir.
